# FORMULARIO COOPERATIVAS

# PROJETO

Formulário Web integrado.

# SOLICITAÇÃO

Foi solicitado a criação de um formulário que fosse integrado ao ArqGED e melhorasse o preenchimento da ficha de cadastro de cooperados da FENCOM que atualmente é preenchida em um PDF editavel no fluxo.  

# ENTREGA

Foi criado um formulário responsivo e intuitivo para facilitar o preenchimento da ficha de cadastro que é exigida no momento do cadastro do novo cooperado, o formulário foi desenvolvido utilizando HTML5, CSS3 e JavaScript. 

Na ficha atual existente no sistema ArqGED o preenchimento não é responsivo e com isso forçava a utilização de um computador para preenchimento, com essa versão criada e integrada o formulário se adapta a todos os dispositivos com acesso a internet. Outro ponto de facilitação é o envio de anexos, atualmente os anexos são enviados "soltos" no fluxo e alguém precisa entrar e validar os arquivos e o cooperado precisa ler um check-list antes de enviar os anexos, na versão integrada os campos de anexos são sinalizados e possibilitam que o cooperado tire foto ou selecione o arquivo solicitado na sua galeria no momento do preechimento, e para facilitar a conferência o arquivo já sai renomeado de acordo com o anexo solicitado.

Nessa nova versão trouxe também uma melhoria de preenchimento, na versão anterior era necessário preencher todos os dados de endereço, agora trouxe uma integração utilizando a API da VIACEP para que ao informar o CEP  os dados de endereço do cooperado sejam carregados de forma automatica na tela facilitando assim o preenchimento das informações.
